# WS4b evidence control

This directory is the bounded evidence control for Cut 6, Workstream 14. It
reuses the accepted WS4a, dense, A0, timing and peer harnesses rather than
copying them.

- `expected_differences.csv` is the finite semantic difference map. A changed
  result outside these decisions is not accepted by this workstream.
- `mode_branch_disposition.csv` assigns each surviving mode-shaped source row
  to preparation, admission, disclosure, results, reopen, an invariant, or the
  named private test seam. None is a second fold behavior profile.
- `check.R` proves the records are complete against the registered claims and
  current mode census, then runs the focused semantic witnesses.
- `records/final/` records final commands and aggregate outcomes only. Private
  market data and generated package artifacts stay outside the repository.

The forced-general-path witness is vacuous after LDG-3176: no fixed-basket
fold specialization survives to force. The common substrate is the only path.
